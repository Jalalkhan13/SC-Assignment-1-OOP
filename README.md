## Tasks

### Task 1 - The Broken Vault

Implemented a DigitalWallet class using encapsulation and enforced balance and PIN rules.

### Task 2 - The Evolving Workforce

Implemented Employee, Developer, and SalesManager classes to demonstrate inheritance and runtime polymorphism.

### Task 3 - Design by Contract

Implemented SmartDevice as an interface with SmartBulb and SmartThermostat implementations.

### Task 4 - AI Code Review

Reviewed AI-generated Java code, identified an OOP design problem, and refactored the problematic code.
